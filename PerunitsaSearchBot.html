PerunitsaSearchBot

Информация о поисковом боте

Имя бота: PerunitsaSearchBot

Версия: 1.0

Тип: Итоговый проект

Назначение: Локальная поисковая система

Создан: 2026

Характеристики бота

  • Соблюдает правила robots.txt
  • Использует вежливый краулинг (задержки между запросами)
  • Идентифицируется как поисковый бот
  • Игнорирует служебные части речи при индексации

Технические детали

Бот создан на основе:

  • Java Spring Boot
  • Морфология русского языка с помощью Lucene.
  • MySQL для хранения данных
  • Jsoup для парсинга HTML

Этот бот — не коммерческий продукт и не подходит для реального использования на производстве без тщательной проверки. Все посещения сайтов осуществляются в соответствии с правилами вежливого краулинга и с учетом файлов robots.txt.
